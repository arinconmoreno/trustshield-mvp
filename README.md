# TrustShield AI — MVP RegTech AI-Native

Plataforma de Gobierno, Riesgo y Cumplimiento (GRC) AI-Native para el mercado B2B/B2G colombiano.

**Módulo:** Modelos de Negocios en Entornos Digitales  
**Programa:** Especialización en Transformación Digital — CEIPA 2026

## Stack

- React 18 + Vite
- Lucide React (iconos)
- CSS-in-JS (inline styles)

## Desarrollo local

```bash
npm install
npm run dev
```

## Deploy en Vercel

1. Sube este repo a GitHub
2. Ve a [vercel.com](https://vercel.com) e inicia sesión con GitHub
3. Click en **"Add New Project"**
4. Selecciona el repo `trustshield-mvp`
5. Vercel detecta Vite automáticamente — click en **Deploy**
6. En ~60 segundos tendrás tu URL pública

## Estructura

```
src/

  main.jsx   — Entry point de React
```
